# Firmware

Pasta reservada à implementação embarcada (ESP32-S3 / ESP-IDF) quando essa etapa começar. Documente placa, versão do ESP-IDF, dependências, forma de entrada do sinal, pré-processamento, modelo usado, consumo de memória, latência e procedimento de teste.

Não conecte diretamente o microcontrolador à rede elétrica. Qualquer aquisição de sinal deve usar instrumentação e condicionamento isolados, adequadamente dimensionados e supervisionados.
