# Dados

Não há conjunto de dados independente versionado nesta pasta neste momento. O notebook gera dados sintéticos e salva artefatos durante a execução.

Para cada conjunto de dados, documente origem, versão do gerador, classes, quantidade de amostras, taxa/passo de amostragem, unidades, transformações, semente aleatória e limitações. Evite versionar arquivos grandes ou dados gerados que possam ser reproduzidos, a menos que isso seja necessário para a reprodutibilidade.
