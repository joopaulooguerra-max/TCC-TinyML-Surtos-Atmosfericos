# Experimentos

Crie um arquivo por execução relevante, por exemplo `EXP-001-baseline-random-forest.md`. Registre objetivo, commit/versão do código, parâmetros, semente aleatória, como os dados foram divididos, métricas por classe, matriz de confusão, observações e limitações. Não compare métricas de experimentos diferentes sem verificar se os conjuntos de teste são comparáveis.
